Ver os preços não precisa de nada. Pra adicionar, remover ou atualizar pelo app, ele precisa de uma chave (token) que só pode mexer no robô deste site. A chave fica salva só neste aparelho.

  1. Abra github.com → criar token (logado na sua conta).
  2. Token name: De Olho no Preço · Expiration: 1 ano (ou o que preferir).
  3. Repository access: Only select repositories → escolha o repositório do site.
  4. Permissions → Repositories → Actions: Read and write. Não precisa de mais nada.

No modo "detectar sozinho", se o nome for de um jogo da Steam ele vira Jogo de PC (Steam, GOG, Nuuvem e Amazon). Se não for, vira Produto (Amazon, KaBuM!, Carrefour e Dafiti). Dá pra trocar o tipo depois, no próprio cartão. Seja específico no nome: "tenis nike air max 90" acha bem melhor que "tenis nike". O link da Steam é opcional. Sem ele, o site procura o jogo pelo nome. Cole o link se ele pegar o jogo errado. A imagem vem sozinha da Steam/Amazon, mas dá pra colar um link de imagem pra usar outra.
