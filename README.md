# De Olho no Preço

site pra acompanhar preço de jogos de pc e de alguns produtos em lojas que eu confio (steam, gog, nuuvem, amazon, kabum, carrefour e dafiti).

o github actions roda a cada 6 horas, salva os preços em dados/historico.json e publica o site no github pages: https://gabrielmartins05.github.io/de-olho-no-preco/

no pc: roda o `Abrir site de precos.bat` (precisa do node) e abre http://localhost:4747
